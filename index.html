CDC Data Status

Latest observation in each key public-health feed on data.cdc.gov.
Unofficial personal project — not affiliated with the CDC.

Checking feeds…

Status is computed in your browser against the page load time: Fresh ≤ 14 days, Stale 15–45 days, Frozen > 45 days (annual feeds: current or previous calendar year). A frozen feed may still be published elsewhere — this checks one known dataset per feed. Queries go directly from your browser to CDC’s public Socrata API; no key, no account, no data collected.

Source: U.S. CDC open data portal (data.cdc.gov), Socrata API. Page is static — no backend, no tracking.
